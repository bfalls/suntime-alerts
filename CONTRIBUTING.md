# Contributing

Thank you for your interest in contributing to Suntime Alerts.

This project is under active development. Contributions are welcome, but please read the guidelines below before opening issues or pull requests.

## Getting Started

- Review the README and Wiki for project context and current status.
- Search existing issues before opening a new one.
- Keep discussions focused on the technical goals of the project.

## Reporting Bugs

If you encounter a bug, please open an issue and include:

- Android version and device (or emulator)
- App version or commit hash
- Clear steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots or logs if relevant

Bug reports without reproduction steps may be closed.

## Feature Requests

Feature requests are welcome, but please note:

- The project prioritizes simplicity and platform correctness.
- Features that conflict with platform conventions or increase complexity may be declined.
- Open an issue and describe the problem you are trying to solve, not just the solution.

## Pull Requests

Before submitting a pull request:

- Ensure the code builds and runs locally.
- Keep changes focused and minimal.
- Follow existing code style and architectural patterns.
- Avoid introducing new dependencies unless clearly justified.

Pull requests should:

- Reference an existing issue when applicable
- Include a clear description of the change
- Avoid unrelated refactoring

Not all pull requests will be accepted. This project is currently maintained by a single primary author.

## Licensing

By contributing to this project, you agree that your contributions will be licensed under the same license as the project.

## Questions

For general questions or clarification, please open a GitHub Issue.

Thank you for your interest and contributions.
